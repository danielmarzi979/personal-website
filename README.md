# EDILMERC - Sito Web Aziendale

Sito web aziendale EDILMERC pubblicato su GitHub Pages.

## Struttura del Progetto

```
personal-website/
|-- index.html          # Pagina principale
|-- styles.css          # Stili CSS
|-- script.js           # JavaScript dinamico
|-- dati_reali_edilmerc.json  # Dati reali dall'app Streamlit
|-- README.md           # Documentazione
```

## Funzionalità

- **Dashboard KPI** con dati reali
- **Gestione Cantieri** con stato avanzamento
- **Monitoraggio Attestati** con scadenze
- **Anagrafica Collaboratori**
- **Registro Documenti** completo
- **Sincronizzazione automatica** con app Streamlit

## Deploy su GitHub Pages

Il sito è pubblicato automaticamente su GitHub Pages all'URL:
`https://[username].github.io/personal-website`

## Aggiornamento Dati

I dati vengono sincronizzati automaticamente dall'applicazione Streamlit:
1. Modifica dati nell'app Streamlit
2. Script genera `dati_reali_edilmerc.json`
3. Commit su GitHub
4. GitHub Pages aggiorna il sito automaticamente

## Tecnologie

- **HTML5** - Semantica moderna
- **CSS3** - Design responsive con variabili CSS
- **JavaScript ES6+** - Dati dinamici e interattività
- **GitHub Pages** - Hosting statico gratuito
